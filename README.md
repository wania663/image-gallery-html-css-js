# 🖼️ Image Gallery with Lightbox

A responsive image gallery built with pure **HTML, CSS and JavaScript**. No libraries.

**Part 2/11** of my HTML CSS JS Series 🚀

## ✨ Features
- Responsive grid layout
- Hover zoom with glow effect
- Lightbox popup viewer
- Next / Previous buttons
- Keyboard support (← → arrows, Esc)
- Image counter

## 🛠️ Tech Stack
- HTML5
- CSS3 (Grid, backdrop-filter, animations)
- Vanilla JavaScript
